# 🚀 Destop GIF

> A feature-rich browser extension that brings rich Tenor GIFs, full-size ASCII art memes, and Kaomoji directly to YouTube comments.

## ✨ Features

- 🎬 **Inline Tenor GIFs:** Search and display animated GIFs seamlessly in YouTube comment threads.
- 🗿 **Epic ASCII & Braille Memes:** Preloaded with classic viral memes (Pop Cat, GigaChad, Doge, Moai, Smug Cat, and more) visible to everyone on all devices.
- 🌸 **60+ Japanese Kaomoji:** Express emotions instantly with one-click emoticons.
- 🎨 **Image-to-Braille Studio:** Convert any image or photo from your computer into high-detail Unicode Braille art ready to post.
- 🛡️ **Anti-Block Architecture:** Designed to work smoothly without triggering YouTube API restrictions or argument errors.

## 📦 Installation

1. Download the latest release `.zip` and extract it.
2. Open your Chromium-based browser (Brave, Chrome, Edge, etc.) and navigate to yourbrowse://extensions/.
3. Enable Developer mode in the top-right corner.
4. Click Load unpacked and select the extracted folder.
5. Open any YouTube video and click the Meme / GIF Studio button in the comment box!
